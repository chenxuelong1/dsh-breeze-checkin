# Breeze 签到

把 [Breeze Blue](https://breezeblue.ai/app/developer) 的开发者账号收进一个本机账号池，勾选后一键串行签到，领取每日积分。

## 它能做什么

- **账号池**：邮箱 + 密码添加账号，添加时先真实登录验证一次，登不上的不会入库。
- **勾选签到**：只签你勾的那几个，没勾的一个都不碰。
- **每日一次**：服务端已经领过的账号直接跳过，不会重复请求。
- **余额与结果**：每行显示当前积分、上次签到结果和实际到账数量。
- **档位可选**：Discord 档 / 普通档。实际发放多少以服务端返回为准。

## 它怎么工作

签到走的是站点自己的 Web 接口，和网页上点「立即领取」是同一条链路：

| 步骤 | 接口 |
|---|---|
| 登录 | `POST /api/auth/email/continue` |
| 读余额与今日状态 | `GET /api/credits/summary` |
| 领取 | `POST /api/credits/daily-claim` |

幂等依据是服务端返回的 `already_claimed`，不是本地日期——本机时钟错了也骗不过服务端。

## 安全边界

- 密码与会话 cookie 存在本机凭据库，不进任何配置文件，界面不回显，日志不打印。
- 所有写操作（添加、删除、签到、改档位）都是 POST 且只接受本机回环地址，别的来源一律 403。
- 请求固定发往 `https://breezeblue.ai`，没有任何配置项能改这个目标。
- 没有定时任务：不点按钮就不会有任何网络请求。

## 已知限制

- **只能登录已注册的账号。** 站点对「新邮箱注册」要求 Cloudflare Turnstile 人机验证，脚本过不去，所以新账号必须先自己在浏览器里注册并登录一次。已有账号可以纯接口登录。
- **会话会过期**，过期后插件会用你保存的密码自动重新登录一次。密码改了就需要删除账号重新添加。
- **积分有效期 30 天**（服务端 `expires_at`），漏签一天就少一天的份额。
- 相邻账号之间固定间隔 600ms，串行执行。这是为了避免多账号同时登录触发风控升级。
- 不读也不显示站点的历史账目、订阅信息或 API Key。

## 怎么用

1. 打开 **设置 → Breeze 签到**。
2. 在「添加账号」填邮箱和密码，点「添加账号」。
3. 勾选要签到的账号，点「签到勾选的账号」。
4. 看每行状态回填：已签到、今天已领、暂无可领、失败。

失败的行会显示具体原因（密码不对、会话失效、接口变更等），照着提示处理即可。
